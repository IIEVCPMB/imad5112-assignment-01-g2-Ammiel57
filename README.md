# Social Spark Android Application

## Project Overview
This is an Android application developed in **Kotlin** using **Android Studio**. The app is designed to provide users with specific "social sparks" or interaction suggestions based on the time of day they input.

## Features
* **Dynamic Suggestions:** Uses nested `if` statement logic to determine the best social interaction for the user.
* **Input Validation:** Checks if the input field is empty before processing.
* **Reset Functionality:** A dedicated button to clear the input and results for a fresh start.
* **Modern UI:** Designed with a clean layout and customized text for better user engagement.

## How to Use
1. Enter a time of day in the text field (e.g., "Morning", "Afternoon", "Dinner").
2. Click the **Suggest message** button to see your social spark.
3. Click **Reset** to clear the screen.

## Technical Details
* **Language:** Kotlin
* **IDE:** Android Studio
* **Logic Structure:** Nested `if` / `else` statements.
* **Version Control:** Managed via GitHub with automated builds using **GitHub Actions**.
